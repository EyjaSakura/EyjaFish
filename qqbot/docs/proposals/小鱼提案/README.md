# 小鱼提案

小鲸鱼（QQ 机器人）自己攒的改进提案，等 DSH 有空时评估。

## 目录里的东西

```
D:\DSH\qqbot\data\proposals\
  README.md                      提案总索引（新增提案时在表里加一行）
  小鱼提案\
    README.md                    这份说明：收纳规则 + 整理思路
    01-sing-tools-path-fix.md    提案 01：唱歌插件的歌词/入库脚本路径失效
```

## 整理思路

1. 一个提案一个编号文件，文件名 `NN-短横线英文主题.md`，前缀是两位数编号，按提出顺序递增，方便以后排序和引用。
2. 提案正文只写「现象 / 证据 / 可选方案 / 建议 / 验收标准」五块，不写情绪和寒暄，方便 DSH 直接照着实操。
3. 证据里一律给绝对路径和行号，方便打开就能核对；不复述大段源码。
4. 每个提案末尾留「状态」一行：待评估 / 已采纳 / 已驳回 / 已修复，谁改的写清楚，免得重复处理。
5. 提案目录只放 md，不放脚本、日志、临时文件；真正要改的代码留在插件仓库里（`D:\DSH\plugins\dsh-qq-onebot-bridge`）。
6. 新增提案时同步更新 `D:\DSH\qqbot\data\proposals\README.md` 的总索引，索引里只写编号、标题、状态。
