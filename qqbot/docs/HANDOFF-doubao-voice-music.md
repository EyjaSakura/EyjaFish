## 你的任务

调研并给出可执行方案：**能否用豆包（字节）的 API 实现「同一个音色既能说话、又能唱歌」，以及怎么接**。

只做调研和方案，不要动生产服务、不要改代码、不要上传任何音频。

## 背景

我在做一个私人 QQ 机器人「小鲸鱼」，现在有两套本地声音能力：

| 能力 | 现状 |
|---|---|
| 说话 TTS | 本地 GPT-SoVITS，音色「小寒」，网关 9998 → 10000-10003 |
| 唱歌 SVC | 本地 so-vits-svc，音色「本兮」，网关 9999 → 10010 |

问题：说话和唱歌是两个音色。想评估用豆包能不能统一，或者至少把「说话」换成豆包复刻音色。

## 需要你搞清楚的问题

1. `doubao-music` 到底能不能开通、开通条件是什么、有没有版本
2. 豆包语音「声音复刻」：
   - 个人账号能否开通、要不要企业实名
   - 计费方式（按次训练？按字符合成？）
   - 训练一次是否可同时用于 TTS 和 S2S
3. 有没有「同音色说话 + 唱歌」的官方路径：
   - 音乐生成是否支持参考音频/指定音色
   - Coze 的 `gen_song_v2` 能不能用
4. 如果不能统一，最接近的方案是什么、成本多少
